## Prepare for the SOE

The native Linux standard is **current Ubuntu LTS − 1 and that release's default CPython minor version**. Provision or migrate to the Ubuntu release selected by the SOE manifest and select its Python interpreter. SOE setup does not perform an operating-system release upgrade. The same target applies to Codio Boxes and VMs, Codespaces, and local Docker under the [approved SOE policy](About-the-SOE).
