## Prepare for the SOE

Use the **CPython minor series supplied by current Ubuntu LTS − 1** for the SOE on macOS. Install the Homebrew formula selected in the SOE manifest, then select its interpreter in VS Code and when creating course virtual environments. Codio Boxes and VMs, Codespaces, and local Docker follow the same Ubuntu/Python target under the [approved SOE policy](About-the-SOE).
